Edukasi dan Visualisasi Bencana Indonesia

Website ini dibuat oleh Tim Doa Ibu untuk membahas kondisi lingkungan dan bencana yang terjadi di Indonesia. Kami ingin menyajikan informasi dengan cara yang mudah dipahami melalui peta interaktif dan penjelasan di dalam website.

Tentang Website

Melalui website ini, kami ingin mengajak pengunjung untuk lebih mengenal kondisi lingkungan di Indonesia, mulai dari kebakaran hutan dan lahan, kualitas udara, hingga aktivitas gunung api.

Informasi disajikan melalui peta dan artikel agar pengunjung bisa melihat persebaran suatu kondisi sekaligus memahami penyebab dan dampaknya bagi masyarakat.

Fitur

- Peta interaktif Indonesia yang dapat digunakan untuk melihat informasi berdasarkan wilayah.
- Informasi dan persebaran titik panas karhutla.
- Visualisasi kualitas udara berdasarkan data PM2.5.
- Peta lokasi gunung api beserta status aktivitasnya.
- Artikel yang membahas penyebab, dampak, serta hal-hal yang berkaitan dengan setiap topik.
- Navigasi untuk berpindah antara halaman website.

Teknologi

Website ini dibuat menggunakan HTML, CSS, dan JavaScript. Leaflet digunakan untuk menampilkan peta interaktif, sedangkan Python digunakan untuk membantu proses pengolahan dan penyusunan dataset.

Alat Bantu Pengembangan

Selama proses pengembangan, kami menggunakan ChatGPT sebagai alat bantu untuk mencari referensi, menganalisis informasi, mengembangkan ide, serta membantu proses penulisan dan revisi kode. Kami juga menggunakan Antigravity untuk membantu proses coding, debugging, dan evaluasi website.

Sumber Data

Beberapa sumber yang digunakan dalam website ini antara lain:

- NASA FIRMS untuk informasi titik panas karhutla.
- Copernicus Atmosphere Monitoring Service untuk data model kualitas udara PM2.5.
- Smithsonian Global Volcanism Program untuk informasi lokasi gunung api.
- MAGMA Indonesia untuk informasi tingkat aktivitas gunung api.

Cara Menjalankan

Website menggunakan file JSON untuk memuat data peta, sehingga disarankan untuk menjalankannya melalui server lokal.

Buka terminal di folder utama project, kemudian jalankan:

```bash
python -m http.server 5500
```

Setelah server berjalan, buka alamat halaman website melalui browser sesuai folder masing-masing.

Penutup

Kami berharap website ini bisa membantu pengunjung memahami informasi mengenai lingkungan dan bencana di Indonesia dengan lebih mudah.

Indonesia merupakan negara kepulauan dengan kekayaan alam dan keanekaragaman hayati yang sangat besar. Oleh karena itu, sudah menjadi tanggung jawab kita bersama untuk menjaga alam yang telah Tuhan berikan dan yang telah dijaga oleh generasi sebelumnya.

Semoga saudara-saudara kita yang sedang menghadapi krisis, musibah, dan bencana segera mendapatkan pertolongan dan keselamatan. Kami berharap informasi yang disajikan melalui website ini dapat menambah pengetahuan serta kepedulian kita terhadap lingkungan dan sesama.
